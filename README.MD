# j2meDash #
j2meDash is a demake version of Geometry Dash ported to Java ME (or J2ME) for Java-supported phones

## Warning
- This project is still experimental and is in its **BETA** phase.
- There is only support for **Nokia Asha 311** (or display size **240x400** + **touchscreen** support). More display size compatibility will be added in the future on this branch.
- Prerequisites and Compilation part is currently **under construction** and therefore shouldn't be compiled using the old guide.

## Running
After you successfully compiled the code, there'll be a new file named `j2meDash4.jar` or `j2meDash8.jar` in the `bin` folder (the folder that contains `compile.sh` and `clean.sh`). Use emulators or real devices.

## Controls
At the moment only **touchscreen** is supported so no control (physical buttons) will be here.
